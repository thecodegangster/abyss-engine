Make Abyss Engine yours

        
Abyss Engine and Hash are made to be changed. The point isn't to use them exactly as they came, it's to edit them until they feel like yours. Every person's Abyss Engine ends up different, because every person reshapes their own: the engine, the compiler, and the language itself.

        
If something bugs you, change it. Don't like how the gamepad looks? Edit the Engine tab. Want a friendlier error message, or a shorter way to write something? Edit the Compiler tab. Think a symbol should work differently, or the language needs a feature it doesn't have? You're allowed to change that too. Nothing in here is off limits, and nobody needs to ask permission.

        
You don't need to be scared of breaking it. A mistake shows an error with the line to fix. A broken compiler is rejected, so the old one keeps running. Save Abyss Engine refuses to save a copy that can't start. And Undo all edits in the File menu puts back the code this file started with. Try things, make a mess, and change it again.

        
When you like what you've built, File > Save Abyss Engine downloads your own version of Abyss Engine, with every change built in. Save a copy before you use Undo all edits if there are changes you want to keep.


        
Hash in four symbols

        
#name[ ] makes a function, and #name(a, b)[ ] gives it inputs. #[ ] and #(x)[ ] are functions with no name, for passing into other functions.

        
{x} = 5 makes a variable, and x = 6 changes it.

        
@(test)[ ... ] runs code when the test is true. Add a second body for "otherwise": @(test)[ yes ][ no ].

        
%(10)[ ... ] repeats 10 times, and %(10, i)[ ... ] counts i from 0 to 9. %(list, item)[ ... ] goes through a list, and %(test)[ ... ] repeats while the test is true.

        
Calling a function never uses #: write move(3). Lines starting with // are notes that Abyss Engine skips.


        
Functions inside functions

        
The last line of a function is its result, so #double(n)[ mul(n, 2) ] gives back twice n.

        
Inner functions can use and change the variables around them. Ending a function with me hands back everything inside it, so enemy(5) can make a fresh enemy that you use as e.x or e.move().


        
Your game

        
#init runs once when the game starts, and #update runs 60 times a second. The screen is 320 by 240 unless you call screen(w, h) in #init.


        
File > Projects keeps up to 8 projects in this browser. Each has its own game code (and any changes you made to the Engine or Compiler tabs). Open, rename, duplicate or delete them there. Work saves to the open project as you type. Projects stay when you open a newer Abyss Engine file in the same browser, but they are not shared between browsers, so use File > Export game to keep a copy.

        
The Game tab can hold several tabs of code. The row under the main tabs lists them: tap + and type a name to add one, tap × to remove one (twice, if it has code in it), and double-tap a name to rename it. They are joined into one program, in order from left to right, so every tab shares the same functions and variables. A variable that runs at start-up must be made in a tab to the left of the code that uses it. Errors show the tab and line.


        
Controls

        
keyDown("left") is true while a button is held. The buttons are "left", "right", "up", "down", "a" and "b". On a keyboard they are the arrow keys or WASD, Space or Z for A, and X for B. On phones, an on-screen pad appears.

        
keyPressed(name) is true only on the frame a button goes down. For tap games, use touching(), touchX(), touchY() or touches(), and call gamepad(false) to hide the pad.


        
Built-in functions

        
Math: add sub mul div mod min max abs floor ceil round sqrt pow sin cos atan2 pi() random(lo, hi)

        
Compare and logic: eq neq lt gt lte gte and or not

        
Text: join(a, b, ...) text(x) number(t) size(t)

        
Lists: list(...) get(l, i) put(l, i, v) push(l, v) pop(l) remove(l, v) removeAt(l, i) has(l, v) keep(l, #(x)[ test ]) size(l)

        
Drawing: clear(color) drawRect(x, y, w, h, color) drawCircle(x, y, r, color) drawLine(x1, y1, x2, y2, color, width) drawText(t, x, y, color, size) textWidth(t, size) screen(w, h) screenWidth() screenHeight()

        
Other: print(...) shows values under the game, and time() gives seconds since the game started.

        
From the engine: every(frames, #[ ]) after(frames, #[ ]) clamp(v, lo, hi) distance(x1, y1, x2, y2) overlap(...) drawCenteredText(...) gamepad(on) frameCount

        
For engine code: padSpace() usePadSpace(on) clipToGame(on) press(name, on) isTouch()


        
Sound

        
Open the Audio view to draw a song on a grid, then press Add to game. Browsers only allow sound after a tap or key press, so a game's first sound may be silent until the player interacts. Try sfx("coin"), or music("C4 E4 G4 E4", 140, "triangle") in #init. See the Reference tab for every sound function.

        
Using JavaScript libraries

        
Add //! use Name https://link lines to a game tab and the library loads before the game starts (see Reference > Libraries). The first time, Abyss Engine asks you to allow each link, once per project. A library can see everything on this page, including your saved projects, so only allow links you trust. File > Export game with libraries downloads each library and builds it into the game file so it works offline. Libraries that are one self-contained file bundle best. If a bundled ES module imports other files, it falls back to loading from the web.

        
Packs

        
The Packs view makes and manages packs: bundles of functions that replace functions in the Engine, Compiler, UI, Save or Game code without editing those tabs. Tap + New pack, choose a function and tap Insert original to start from the real one, then edit it. Turn it On and the game restarts with it. Pack my edits turns changes you already made in the system tabs into packs and puts the tabs back to the original. Export and Import share packs as text files. Imported packs start off. Turning on a pack for the Compiler, UI or Save asks first, because it can change how everything works, including saving. If a pack breaks the build it is turned off. Safe mode ignores all packs, in case something goes wrong. Packs are shared by all projects, and a copy of Abyss you save carries them along.

        
Editing Abyss Engine itself

        
The Engine tab is Abyss Engine's own code, written in Hash. It runs the main loop, timers and the phone gamepad, and everything it makes is available to your game. Change it and press Run to try your version.

        
The UI tab is the editor itself (tabs, code view, error bar, File menu, symbol tentacle), written in Hash. Run checks your edits, and they start up the next time Abyss Engine loads. If your UI code breaks, the built-in UI runs instead and tells you why. Extra built-ins for UI code: dom domAll doc make on later fire exec active media css escape split find findLast. DOM objects work with . like any object.

        
The Save tab is the save system: the Hash code that keeps your projects in the browser and loads them back (it uses jsonRead, jsonWrite and storeGet/storeSet). Edit it, press Run to check it, and it starts working the next time Abyss Engine loads. If it breaks, the built-in one runs instead and tells you why. Careful: it controls how all your projects are saved, so use File > Export game to keep a copy of anything important first.

        
The Packer tab is the pack system itself, the Hash code behind the Packs view. Edit it, press Run to check it, and it starts working the next time Abyss Engine loads. It runs in two steps: your Packer code starts first and patches its own source with any packs whose target is packs, then the patched version takes over. If your Packer code breaks, the built-in one runs, and if a pack aimed at it breaks it, that pack is skipped, with a message each time. Careful: a Packer that misbehaves without breaking can change how every pack applies, so turn on Safe mode in the Packs view or use File > Export game to keep a copy first.

        
The Compiler tab is the Hash compiler, also written in Hash. It turns all Hash code into JavaScript, including its own code. When you change it and press Run, Abyss Engine rebuilds the compiler with itself twice and only switches to your version if both builds come out exactly the same. If something goes wrong, the old compiler keeps running.

        
Extra built-ins the compiler uses: slice(t, a, b) lower(t) upper(t) map() keys(m) joinList(l, sep) quote(t) fail(message, file, line, col) builtins(). get, put, has and size work on maps too.

        
Your edits are kept in this browser automatically. File > Save Abyss Engine downloads a new copy of Abyss Engine with your edits built in, and it only saves when everything runs, so a broken edit can't stop the saved copy from starting.

      

      

        
Every built-in, one by one

        
Built-ins are called like any function, with no #. Inputs in brackets like (a, b, ...) mean "as many as you like", and inputs left out use their default. DOM elements and maps use . or get and put.

        
Math

        
add(a, b, ...) Adds any number of numbers.

        
sub(a, b) a minus b.

        
mul(a, b, ...) Multiplies any number of numbers.

        
div(a, b) a divided by b. Dividing by 0 is an error.

        
mod(a, b) Remainder of a ÷ b, never negative (mod(-1, 3) is 2).

        
min(a, b, ...) Smallest of the numbers.

        
max(a, b, ...) Largest of the numbers.

        
abs(n) Number without its minus sign.

        
floor(n) Rounds down.

        
ceil(n) Rounds up.

        
round(n, places) Rounds to the nearest whole number, or to places decimals.

        
sqrt(n) Square root.

        
pow(a, b) a to the power b.

        
sin(r) Sine of an angle in radians.

        
cos(r) Cosine of an angle in radians.

        
atan2(y, x) Angle in radians of the point (x, y).

        
pi() 3.14159…

        
random(lo, hi) Random number from lo to hi. With two whole numbers it gives a whole number, and hi can be picked. Otherwise it gives a decimal. With no inputs: 0 up to 1.

        
Compare and logic

        
eq(a, b) True if a and b are the same.

        
neq(a, b) True if they are different.

        
lt(a, b) a is less than b.

        
gt(a, b) a is greater than b.

        
lte(a, b) a is less than or equal to b.

        
gte(a, b) a is greater than or equal to b.

        
and(a, b, ...) True if every input is true.

        
or(a, b, ...) True if any input is true.

        
not(x) Flips true and false.

        
Text

        
join(a, b, ...) Turns every input into text and glues them together.

        
text(x) Any value as text.

        
number(t) Reads a number from text. Gives 0 if it isn't one.

        
size(x) Length of text or a list, or how many keys a map has. Nothing gives 0.

        
slice(t, a, b) Part of text or a list from position a up to, not including, b. Counting starts at 0.

        
lower(t) Lowercase text.

        
upper(t) Uppercase text.

        
quote(t) Text wrapped in double quotes, with special characters escaped.

        
split(t, sep) Cuts text into a list of pieces wherever sep appears.

        
find(t, s, from) Position of the first s in t, starting at from. -1 if missing.

        
findLast(t, s, from) Position of the last s in t, searching backward from from. -1 if missing.

        
escape(t) Makes text safe to put in HTML (& < >).

        
Lists and maps

        
list(a, b, ...) Makes a list. Positions start at 0.

        
map() Makes an empty map, which stores values under text keys.

        
keys(m) List of a map's keys.

        
get(l, i) Item i of a list, or the value stored under key i in a map.

        
put(l, i, v) Sets item i of a list, or key i of a map, to v. Gives back v.

        
push(l, v) Adds v to the end of a list.

        
pop(l) Removes the last item and gives it back.

        
removeAt(l, i) Removes item i and gives it back.

        
remove(l, v) Removes the first item equal to v. True if one was found.

        
has(x, v) List: contains v? Map: has key v? Text: contains v?

        
joinList(l, sep) Turns each item into text and joins them with sep.

        
keep(l, test) New list with only the items where test(item) is true. The original isn't changed.

        
Drawing

        
clear(color) Fills the whole screen with a color. Default black.

        
drawRect(x, y, w, h, color) Filled rectangle. (x, y) is the top-left corner.

        
drawCircle(x, y, r, color) Filled circle centered on (x, y).

        
drawLine(x1, y1, x2, y2, color, width) Line between two points. Width defaults to 1.

        
drawText(t, x, y, color, size) Text with its top-left corner at (x, y). Size defaults to 12.

        
textWidth(t, size) How wide the text would be when drawn.

        
screen(w, h) Sets the game size (1 to 4000 each). Call it in #init. Default 320 by 240.

        
screenWidth() Game width.

        
screenHeight() Game height.

        
padSpace() Extra pixels the engine leaves under the game for the phone pad. 0 when there is none.

        
usePadSpace(on) Allows or stops that extra space.

        
clipToGame(on) While on, drawing is cut off at the game's edges. The engine uses it around #update.

        
Input

        
keyDown(name) True while the button is held: left, right, up, down, a, b. Keyboard keys work too, like "space".

        
keyPressed(name) True only on the frame the button goes down.

        
touching() True while a finger or the mouse is down on the game.

        
touchX() X of the first touch, in game pixels.

        
touchY() Y of the first touch, in game pixels.

        
touches() List of every touch, each with .x and .y.

        
press(name, on) Makes a button count as held or released. The phone pad uses it.

        
isTouch() True on touch screens.

        
Other

        
print(a, b, ...) Shows values in the log under the game. The last 100 lines are kept.

        
time() Seconds since the game started.

        
fail(message, file, line, col) Stops with an error shown at that file and line.

        
builtins() List of every built-in name.

        
From the engine tab

        
clamp(v, lo, hi) Keeps v between lo and hi.

        
distance(x1, y1, x2, y2) Straight-line distance between two points.

        
overlap(ax, ay, aw, ah, bx, by, bw, bh) True if two rectangles touch.

        
drawCenteredText(t, x, y, color, size) Like drawText, but centered on (x, y).

        
every(frames, action) Runs action every so many frames (60 per second).

        
after(frames, action) Runs action once, after so many frames.

        
gamepad(on) Shows or hides the phone pad. Hide it for tap games.

        
frameCount Frames since the game started. A variable, not a function.

        
Sound (Engine tab, plus synth and silence)

        
sfx(name) Ready-made effects: "jump", "coin", "select", "laser", "hit", "explode", "powerup".

        
play(song, bpm, wave) Plays a song once and gives back its length in seconds. Steps are separated by spaces and last one beat each: a note like "C4", "C#5" or "Eb3", a chord like "C4+E4+G4", a drum ("kick", "snare", "hat") or "-" for a rest. "G4:2" holds for 2 beats. Defaults are 120 bpm and "square". Waves: "sine", "square", "saw", "triangle".

        
music(song, bpm, wave) Loops a song until stopMusic() or another music call. Make songs in the Audio view.

        
stopMusic() Stops the loop and silences everything.

        
sound(wave, freq, secs) One tone, like sound("square", 440, 0.2).

        
volume(v) Master volume from 0 to 1. mute(on) turns all sound off or on.

        
noteFreq(name) Frequency of a note like "A4" (440). Rests give 0.

        
tones(rows, delay) Plays a list of tones, each list(wave, freq, endFreq, secs, volume, delay), which is how sfx is built.

        
synth(wave, freq, endFreq, secs, vol, delay) The one JavaScript tone-maker underneath. Pitch slides from freq to endFreq. Volume is 0 to 1. Gives back false if the browser has no audio.

        
silence() Cuts off every sound that is still playing.

        
Libraries

        
Put //! use Name https://link at the top of a game tab to load a JavaScript library from the web before the game starts. Add module at the end for ES modules, like //! use THREE https://cdn.jsdelivr.net/npm/three@0.160.0/+esm module. Links must start with https://.

        
lib(name) The library you loaded: the module, or window[name] for a classic script. Use . to read from it and call it, like {v} = lib("THREE").Vector3.

        
create(Class, a, b, ...) Makes a new object from a library's class, like new in JavaScript: create(lib("THREE").Vector3, 1, 2, 3).

        
use(name, url, kind, code, done) The loader behind //! use. Kind is "script" or "module". Pass the library's text as code (or false to use the link). done(true) runs when it loaded, otherwise done(errorText).

        
fetchText(url, done) Downloads text, then runs done(text), or done(false) if it failed. The site must allow it.

        
Packs

        
A pack is text: //@ pack Name, //@ target engine (or game, compiler, ui, store, packs), then top-level functions like #name[ ... ] and variables like {name} = 5. A function with the same name as one in the target replaces it, and a new name is added. The target tab's own text is never changed. Later packs in the list win over earlier ones. Make and manage them in the Packs view.

        
Only top-level functions and variables can be replaced, not ones inside another function. Errors in a pack show as Pack Name. Packs apply to every project.

        
Data and saving

        
jsonRead(text) Turns JSON text into lists and maps. Gives false if the text isn't valid JSON.

        
jsonWrite(value) Turns lists, maps, text, numbers and true/false into JSON text.

        
storeGet(key) Text saved in the browser under a key, or false. storeSet(key, text) saves it and gives back true if it fit. storeRemove(key) deletes it. Games can use these for high scores. Start your keys with your game's name, because Abyss Engine uses keys starting with "abyss-engine:" for its own saves.

        
clock() Milliseconds since 1970, handy for ids and dates.

        
For UI code (UI tab)

        
dom(selector) The first page element matching a CSS selector.

        
domAll(selector) List of all matching elements.

        
doc() The page's document.

        
active() The element that has focus.

        
make(tag) Makes a new element, like make("button").

        
on(el, event, fn) Runs fn(e) whenever the event happens on el.

        
later(ms, fn) Runs fn once after ms milliseconds.

        
fire(el, event) Sends an event to el, like "input".

        
exec(command, value) Runs a browser editing command like "insertText" or "undo". True if it worked.

        
media(query) True if a CSS media query matches, like "(max-width: 820px)".

        
css(el, property) Current style value, like css(el, "lineHeight").
