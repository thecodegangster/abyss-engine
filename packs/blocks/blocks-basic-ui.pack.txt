//@ pack Blocks Basic (UI)
//@ target ui
// The first set of blocks for the block editor: the hat blocks that start a game (#init, #update, #draw),
// drawing, buttons and touch, variables, math, comparisons, loops, lists, functions, sound and notes.
// (if / else and Raw Hash come with Blocks Core.)
//
// Most inputs take Hash as typed text, like 10, "hello", or score. Drop a round or pointed block
// into an input to use its answer instead. An input left empty uses the grey example in it.
//
// Define blocks have a + to add inputs (each gets a name), a category box, and an "answer" switch. Every function
// shows up as its own block in the category it was put in (a round block if it gives an answer), with its inputs.
//
// Careful with and / or: like Hash itself, both blocks work out all of their inputs.
//
// To add more blocks, make a pack like this one: list Blocks Core (UI) as a dependency and call
// bkDef / bkAddBlock (see the top of Blocks Core (UI)).
//
// Dependencies: Blocks Core (UI). Blocks Editor (UI) is needed to see and use the blocks. Turn Core on first.
// This pack only adds block kinds. Every name it adds starts with bkb.

// Adds a step, round or pointed block. defs is a list of input name, example, input name, example...
#bkbAdd(type, shape, cat, parts, tpl, defs)[
  {d} = bkDef(type, shape, cat, type)
  d.parts = parts
  d.tpl = tpl
  %(div(size(defs), 2), i)[ put(d.defaults, get(defs, mul(i, 2)), get(defs, add(mul(i, 2), 1))) ]
  bkAddBlock(d)
]

// Adds a block that wraps code. slots are the names of the bodies ("" for none), mids the code between them.
#bkbWrap(type, shape, cat, parts, open, slots, mids, defs)[
  {d} = bkDef(type, shape, cat, type)
  d.parts = parts
  d.open = open
  d.slots = slots
  d.mids = mids
  d.close = "]"
  %(div(size(defs), 2), i)[ put(d.defaults, get(defs, mul(i, 2)), get(defs, add(mul(i, 2), 1))) ]
  bkAddBlock(d)
]
